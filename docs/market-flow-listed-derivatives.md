# Listed derivatives lifecycle

## Scope

This guide covers the illustrative lifecycle for exchange-traded derivatives.
It is separate from the existing bilateral OTC contract, confirmation, collateral, and clearing guide.

## Stages

1. Execute a standardised listed contract on an exchange.
2. Submit through an FCM or clearing member for an eligible cleared trade.
3. Run daily mark-to-market and margin operations.
4. Follow product terms for expiry, exercise, cash settlement, or delivery.

## Evidence boundary

The CME Clearing educational source supports the described clearing roles and daily mark-to-market process. Map arcs remain illustrative, not transaction locations, legal positions, live margin calls, or a claim of service coverage in each city.
