# Securities issuance expansion plan

The new issuance library keeps a fixed boundary: it explains public, source-linked procedural paths. It does not show live orders, eligibility, prices, allocations, legal advice, or investment recommendations.

Thirty independently reviewable increments are planned: the library shell, U.S. Treasury auction, Treasury bills, notes, bonds, TIPS, FRNs, reopening, cash-management bills, savings bonds, corporate IPO registration, follow-on equity offering, rights offering, preferred stock, convertible notes, investment-grade corporate bonds, high-yield bonds, municipal bonds, municipal private placement, agency MBS, Ginnie Mae MBS, ABS, CMBS, CLO, ETF creation, mutual-fund shares, closed-end fund IPO, REIT IPO, ADR depositary issuance, and direct-registration offering.

Each increment must add a plainly labelled procedure, a source link, and a scope boundary, then pass data validation, unit tests, build, rendered smoke, PR review, merge, and main-branch CI.
